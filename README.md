# Dev Cafeteria ☕

Este projeto é uma landing page moderna para uma cafeteria, desenvolvida como parte do currículo de programação do **DEVClub**. O objetivo principal foi consolidar conhecimentos em marcação semântica e estilização profissional.


## 🚀 Sobre o Projeto

O **Dev Cafeteria** é um site institucional simples e elegante que apresenta os produtos, o ambiente e o contato da cafeteria. O foco do desenvolvimento foi criar uma interface limpa, com boa hierarquia visual e facilidade de navegação.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais da web:

* **HTML5:** Para a criação da estrutura do site, utilizando tags semânticas para melhorar a acessibilidade e o SEO.
* **CSS3:** Para a estilização completa, incluindo o uso de:
    * **Flexbox:** Para organização e alinhamento dos elementos na tela.
    * **Google Fonts:** Para a integração de tipografias personalizadas.
    * **Posicionamento:** Uso de propriedades de display e box model para um layout equilibrado.

## 🏗️ Como o projeto foi criado

O processo de desenvolvimento foi dividido em etapas lógicas:

1.  **Planejamento da Estrutura:** Organização das seções (Home, Sobre, Cardápio e Contato) dentro do HTML.
2.  **Estilização Global:** Definição de cores, fontes e reset de estilos padrões.
3.  **Componentização Visual:** Estilização individual de botões, cards e menus utilizando classes CSS.
4.  **Refinamento:** Ajuste de margens, preenchimentos e alinhamentos para garantir a fidelidade ao design proposto.

## 💻 Como rodar o projeto

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/91douglasfariasantos/DEVCAFE.git](https://github.com/91douglasfariasantos/DEVCAFE.git)
    ```
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` em seu navegador de preferência.
